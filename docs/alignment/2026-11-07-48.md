## What changed
`/` is now the orders list (status, search and page in the URL:
`/?status=paid&q=ana&page=2`) instead of the M1 health panel. Order numbers
link to `/orders/<number>`, a route that the `order-detail` task still has to
provide. New shared components: `Pagination`, `OrdersResults` (table from
`--bp-md`, cards below). The health panel, `useHealth` and `getHealth` are removed.

## What the others relied on (before → after)
- `/` shows "Orders — API ok" → shows the list; the health check is no longer
  called by the web app.
- `/orders/<number>` does not exist yet → the list links to it (a link to it
  currently has no matching route).
- No contract change: `GET /api/v1/orders` as already in `openapi.yaml`.
