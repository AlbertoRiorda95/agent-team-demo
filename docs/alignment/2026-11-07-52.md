## What changed
New route `/orders/:number` (order detail page) with the Cancel dialog, toast and
conflict/error states. Links in the orders list now carry the list query in the
router state (`fromSearch`) so "Back to orders" returns to the same filter,
search and page. `useWide` moved to `lib/useWide.ts` (shared by the list and the
lines table). No contract or token change.

## What the others relied on (before → after)
- `/orders/:number` fell into the catch-all and showed Not found → it shows the
  order; malformed numbers and 404 still show Not found.
- List links to an order had no router state → they pass `{ fromSearch }`.
