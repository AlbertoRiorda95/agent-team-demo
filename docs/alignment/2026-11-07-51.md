## What changed
New shared components `Button` (primary, secondary, danger, busy), `Dialog`
(native `<dialog>`, modal) and `Toast` (`role="status"`, 5 s), plus a Not found
page. A catch-all route `*` inside the shell now shows it, so unknown URLs no
longer render an empty page; a signed-out visitor goes through login first.
Tokens: none added (danger uses `--color-danger`).

  a "Back to orders" link.

  it falls into the catch-all and shows Not found.
